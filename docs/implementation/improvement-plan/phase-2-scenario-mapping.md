# Phase 2: Original-Szenarien und fachlicher Port

Das [unveränderte Phase-1-Inventar](original-scenarios.json) hält alle 87
Originalmethoden einschliesslich einer historisch inaktiven FTP-Methode und
aller Originalassertionen fest. Diese Tabelle ordnet jeden Fall konkret zu.
Die vollständigen ursprünglichen Assertionstexte stehen zusätzlich in der
[maschinenlesbaren Zuordnung](phase-2-scenario-mapping.json). Die tatsächlichen
Root-Prüfwege, Ergebnisse und ausgeführten Artefakthashes stehen im Phasenbericht;
Implementierung allein wird nicht als erfolgreicher Lauf ausgegeben.

Gleichwertige Fälle erhalten das jeweilige fachliche Orakel; Änderungen an
Tabellenschema-Isolation, Syntax, Bibliotheksprojektion oder Locale stehen
explizit pro Zeile. Eingabedateien werden im kanonischen Jobbestand gebündelt,
SQL-/Modellabhängigkeiten lokal bereitgestellt und unabhängig gelesen.
Die Original-Gradle-Builds selbst werden nicht als Runtimejobs ausgeführt.
