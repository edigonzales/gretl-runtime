## 6. Eigene neue Gegenproben

**CP-F3 – kontrollflussgeschützte innere Invocationen/Referenzen (neu, nicht Kopie eines vorhandenen Tests):**

- Hypothese: Wenn ein innerer `ctx.run`, ein `result(...)` oder ein `parameter(...)` in einem nicht ausgeführten `if`-Zweig steht, darf der statische Kern keinen bewiesenen ERROR melden; die reale Runtime überspringt den Zweig.
- Neue Fixture/Geste: sechs Fixtures, insbesondere
  - `task('p', Echo) { text='x' }; task('t', Echo) { text='x'; if (false) { ctx.run(RequiredText) { } } }; defaults 't'`
  - `parameter('flag',description:'F',type:'boolean',defaultValue:false); action('a') { if (parameter('flag')) { ctx.run(RequiredText) { } } }; defaults 'a'`
  - `action('a') { if (false) { result('p').missing } }; defaults 'a'` (mit Producer `p`)
