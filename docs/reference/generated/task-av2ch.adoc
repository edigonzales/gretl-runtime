[cols="4,6,1", options="header", role="gretl-task-properties"]
|===
| Feld | Beschreibung | Erforderlich

| [.dsl-signature]#*inputFiles* = list#
| Liste der lokalen [.acronym]#INTERLIS#-1-Transferdateien für die AV-Konvertierung. +
Beispiel: [.code-fragment]#`inputFiles = [file('data.itf')]`#
| [.required]#ja#

| [.dsl-signature]#*outputDirectory* = path#
| Verzeichnis für die erzeugten Dateien; für dauerhafte Ausgaben einen externen Pfadparameter verwenden. +
Beispiel: [.code-fragment]#`outputDirectory = parameter('output')`#
| [.required]#ja#

| [.dsl-signature]#*modeldir* = text#
| Lokales Modellverzeichnis als Path (etwa [.dsl-method]#`file('models')`#) oder unveränderter Suchpfadtext der Fachbibliothek; mehrere Verzeichnisse nach deren Regeln trennen. +
Beispiel: [.code-fragment]#`modeldir = file('models')`#
| [.optional]#nein#

| [.dsl-signature]#*language* = text#
| Sprache des Bundesmodells: de für Deutsch oder it für Italienisch. +
Vorgabe: [.code-fragment]#`'de'`# +
Beispiel: [.code-fragment]#`language = 'de'`#
| [.optional]#nein#

| [.dsl-signature]#*zip* = boolean#
| Die erzeugten Dateien als ZIP-Archive ausgeben. +
Vorgabe: [.code-fragment]#`false`# +
Beispiel: [.code-fragment]#`zip = true`#
| [.optional]#nein#

|===
