|===
| Feld | Beschreibung | Erforderlich

| [.dsl-signature]#*itfFiles* = list#
| Liste der lokalen [.acronym]#INTERLIS#-1-Transferdateien für die AV-Konvertierung. +
Beispiel: [.code-fragment]#`itfFiles = [file('data.itf')]`#
| [.required]#ja#

| [.dsl-signature]#*dxfDirectory* = path#
| Verzeichnis für erzeugte [.acronym]#DXF#-Dateien beziehungsweise ZIP-Archive. +
Beispiel: [.code-fragment]#`dxfDirectory = path('build/dxf')`#
| [.required]#ja#

| [.dsl-signature]#*modeldir* = text#
| Lokales Verzeichnis beziehungsweise Suchpfad der für die Konvertierung benötigten Modelle. +
Beispiel: [.code-fragment]#`modeldir = file('models')`#
| [.optional]#nein#

| [.dsl-signature]#*logFile* = path#
| Pfad für das Protokoll der Fachbibliothek. +
Beispiel: [.code-fragment]#`logFile = file('build/av2geobau.log')`#
| [.optional]#nein#

| [.dsl-signature]#*proxy* = text#
| Hostname des [.acronym]#HTTP#-Proxys für Repository-Zugriffe der Fachbibliothek. +
Beispiel: [.code-fragment]#`proxy = 'proxy.example'`#
| [.optional]#nein#

| [.dsl-signature]#*proxyPort* = integer#
| Port des [.acronym]#HTTP#-Proxys; zusammen mit proxy verwenden. +
Beispiel: [.code-fragment]#`proxyPort = 8080`#
| [.optional]#nein#

| [.dsl-signature]#*zip* = boolean#
| Die erzeugten Dateien als ZIP-Archive ausgeben. +
Vorgabe: [.code-fragment]#`false`# +
Beispiel: [.code-fragment]#`zip = true`#
| [.optional]#nein#
